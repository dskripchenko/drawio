# Начало работы

```sh
npm install @dskripchenko/drawio
```

```ts
import { render } from '@dskripchenko/drawio'

const { svg, width, height, page, pages, warnings } = render(fileText)
container.innerHTML = svg
```

`render` принимает текст файла `.drawio` — со сжатыми или обычными
страницами, — голый `<mxGraphModel>` или SVG, выгруженный вместе с диаграммой
(`.drawio.svg`), и рисует одну страницу.

| Поле       | Что это                                                               |
| ---------- | --------------------------------------------------------------------- |
| `svg`      | Рисунок — готовый элемент `<svg>` текстом                             |
| `width`    | Ширина в пикселях                                                     |
| `height`   | Высота в пикселях                                                     |
| `page`     | Нарисованная страница: `{ index, id, name }`                          |
| `pages`    | Названия всех страниц — для переключателя                             |
| `warnings` | Что стало заглушкой: фигуры поставщиков, картинки не из файла         |

## Параметры

```ts
render(fileText, {
  page: 'Architecture', // номер, id или название; по умолчанию первая страница
  title: 'Поток заказа', // доступный заголовок; по умолчанию название страницы
  idPrefix: 'flow', // id внутри SVG; уникальный, если файл на странице дважды
  padding: 10,
  measureText, // как измерять текст; в браузере по умолчанию canvas
  allowExternalImages: false, // загружать картинки с адресов http(s)
  limits: { maxLength: 5_000_000 }, // пределы XML
  maxPageSize: 10_000_000, // во сколько байт может распаковаться сжатая страница
})
```

## Что рисуется

Фигуры общих библиотек и блок-схем — прямоугольники, эллипсы, ромбы,
треугольники, шестиугольники, параллелограммы, трапеции, цилиндры,
документы, облака, процессы, заметки, карточки, выноски, люди, шаги,
задержки, дисплеи, хранилища, блочные стрелки, кресты, дорожки
(горизонтальные и вертикальные), таблицы, текст, линии — с заливками,
градиентами, обводкой, пунктиром, прозрачностью, поворотом и отражением.
Соединители с прямой, ортогональной, коленчатой и ER-трассировкой, точками
излома, скруглёнными и кривыми линиями, фиксированными точками крепления и
наконечниками draw.io, с подписями. Контейнеры, группы и слои; скрытые слои
и содержимое свёрнутых контейнеров остаются скрытыми. Подсказки и ссылки
`UserObject`, а также `%подстановки%` в подписях.

Фигуры библиотек поставщиков (`mxgraph.aws4.*`, `mxgraph.azure.*`, …) не
рисуются — их картинки принадлежат владельцам, — а показываются пунктирной
рамкой с названием фигуры.

## Оформление

Цвета, заданные в файле, рисуются как заданы. Где файл оставил значения по
умолчанию, действуют CSS-переменные — так страница может показать такие
диаграммы в тёмной теме:

| Переменная                   | По умолчанию | Для чего                          |
| ---------------------------- | ------------ | --------------------------------- |
| `--drawio-font-family`       | Helvetica…   | Текст без своего шрифта           |
| `--drawio-background`        | transparent  | Фон рисунка                       |
| `--drawio-fill`              | `#ffffff`    | Заливка по умолчанию              |
| `--drawio-stroke`            | `#000000`    | Линии по умолчанию                |
| `--drawio-text`              | `#000000`    | Текст по умолчанию                |
| `--drawio-label-background`  | `#ffffff`    | Фон подписей соединителей         |
| `--drawio-placeholder`       | `#9ca3af`    | Заглушки                          |

Текст на фигуре, которую залил файл, сохраняет цвет из файла — чтобы на этой
заливке он читался в любой теме.

## Чтение модели

```ts
import { parseDrawio } from '@dskripchenko/drawio'

const file = parseDrawio(fileText)
file.pages[0].cells.get('api') // { id, parent, value, style, vertex, edge, geometry, data, … }
```

Ошибки — `DrawioError`, со строкой и столбцом, когда они известны.
